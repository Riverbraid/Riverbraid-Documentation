# Witness Model

**Status**: DRAFT / INFORMATIVE
**Authority boundary**: Documentation only
**Total safety claim**: NONE

## Purpose

This document defines witness types and what they can and cannot prove.

## Possible witness categories

- hash witness
- Merkle style witness
- signature witness
- workflow witness
- registry witness
- coherence witness
- future witness profile

## Boundary

A witness is evidence of a bounded condition.

A witness is not proof of total safety.

This document does not add, rotate, or verify any witness.

Witness implementation requires a separate explicit gate.
