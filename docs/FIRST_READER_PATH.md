# First Reader Path

**Status**: SCAFFOLD / INFORMATIVE
**Authority boundary**: Documentation only
**Implementation claim**: NONE
**Verification claim**: NONE

## Purpose

This document defines the public entry path for a serious first time Riverbraid reader.

Riverbraid should be easy to approach without becoming easier to misunderstand.

A serious technical reader should be able to understand Riverbraid without needing the builder in the room.

## Reader questions this path must answer

1. What is Riverbraid?
2. What is this repository's role?
3. What can be inspected or verified?
4. What is not being claimed?
5. Where should the reader go next?

## Preferred reader path

1. Riverbraid Evaluation Kit
2. Riverbraid Core
3. Riverbraid Documentation
4. Riverbraid Golds
5. Selected domain surfaces

## Entry route

Start with Riverbraid Evaluation Kit.

The Evaluation Kit is the public start path and proof route for first time technical inspection.

Then inspect Riverbraid Core.

Core remains the normative protocol authority surface.

Then use Riverbraid Documentation for explanation, boundaries, and navigation.

Then explore Riverbraid Golds and selected domain surfaces only after understanding their maturity labels and evidence boundaries.

## What a first reader should not assume

A first reader should not assume certification, legal approval, production readiness, external audit, complete AI safety, absolute security, absence of defects, compliance certification, regulatory approval, adoption, or registry freshness.

## Next honest actions

A reader may:

- inspect the Evaluation Kit
- review the pinned registry
- inspect Core authority language
- run or review the available verification path
- open a technical question
- treat experimental or directional repositories as scaffold unless evidence says otherwise

Every public surface should make the next honest action obvious.
