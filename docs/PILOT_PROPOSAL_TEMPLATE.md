# Pilot Proposal Template

**Status**: Template

Use this template to describe a possible Riverbraid-aligned pilot.

## Basic fields

```yaml
pilot_name:

domain:
project_owner:
contact_surface:
data_sensitivity:
required_evidence:
verifier_depth:
governance_owner:
failure_behavior:
public_benefit:

```

## Required boundary

Every pilot proposal should state what it does not claim.

## Boundary

This template does not approve a pilot. It only standardizes review information.
