# Repo Readiness Matrix

**Status**: TEMPLATE / INFORMATIVE
**Authority boundary**: Self assessment scaffold only
**Certification claim**: NONE
**External audit claim**: NONE

## Purpose

This document defines the repository readiness matrix shape for Riverbraid.

The matrix is not populated by this scaffold.

A YES entry in a future populated matrix does not imply certification, production readiness, security hardening, external audit, or absence of defects.

## Matrix fields

Future population should track:

- repository
- purpose
- lifecycle status
- repository class
- README present
- setup path present
- test command present
- CI present
- release tags present
- security contact present
- contribution path present
- license present
- integration status
- dependency direction
- authority boundary
- owner or stewardship boundary
- role narrative present
- verification path present
- repository description present
- GitHub topics present
- README start path present
- README non claims present
- evidence path addressable
- help path present
- issue path present
- security report path present
- contribution posture stated
- contribution guide present
- code of conduct present if contribution is open
- support or contact path present
- next reader link present
- claim to evidence traceability present

## Special rule

Flag any repository that has a role narrative but no verification path.

A repository with a strong role narrative but no verification path must be labeled readable but not mechanically mature.

Only use actual current repositories when populating the matrix.

Do not include imagined or future repository names unless they are clearly placed in a separate concept or experimental section.
