# Release Scope
The next release should be narrow.
## Recommended release name
`v0.1.0-governance-floor`
## Release scope
This release should include:
- The Phase 24 verified 30 repository registry claim.
- The Phase 25E local outer surface alignment claim.
- Documentation explaining how to inspect the system.
- Clear claim levels.
- Clear non claims.
## Do not include
Do not claim:
- External reproduction.
- Third party certification.
- Complete AI governance coverage.
- Absence of defects.
- Full domain maturity across every repository.
- That every repository in the organization belongs to the verified 30 registry.
## Release wording
Riverbraid v0.1.0-governance-floor establishes a public, inspectable starting point for AI governance, transparency, and trust. It records a verified 30 repository functional registry and a locally verified outer surface alignment. It is intended as a governance floor, not a complete governance institution.
## Release artifacts to reference
- Phase 24 final anchor.
- Phase 25C outer repo repair plan.
- Phase 25E post alignment verification.
- Core README.
- Documentation claim level table.
- Repository boundary map.
## Done condition
The release is valid when the tag points to the commit containing the public documentation package and the latest verification artifacts, and CI passes for that commit.
