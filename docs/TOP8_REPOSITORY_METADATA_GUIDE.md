# Top 8 Repository Metadata Guide

This document records the recommended public metadata for the top 8 Riverbraid repositories.

It is a visibility surface only. It does not update GitHub repository About fields or topics by itself.

It does not define protocol authority, verification rules, governance claims, or technical correctness.

## Scope

The recommendations below are intended for manual application through the GitHub web interface or GitHub CLI.

They improve public readability and discoverability only.

## Non claims

Applying this metadata does not claim:

- More adoption
- More technical maturity
- More verification
- More safety
- More production readiness
- External audit
- Third party certification
